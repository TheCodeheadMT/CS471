Formal Problem Definition

Before an AI can search for a route, the problem must be formally defined into these four components.

1. States ($S$)

A physical configuration. Here, it is the specific waypoint the aircraft is currently located at.

$S = \{Start, A, B, C, Goal\}$

2. Actions ($A$)

The legal moves available. E.g., choosing which adjacent flight corridor to take next.

$A(s) = \{\text{Fly to } x, \text{Fly to } y\}$

3. Successor Function

The transition model. Given a state and action, what is the new state and the step cost?

$T(s, a) = (s', c)$

Ex: $T(S, \text{Fly to B}) = (B, 12)$
Cost: $c(S, B) = 12$

4. Goal Test

A function that evaluates the current state to determine if the mission objective is achieved.

Is $s == Goal$?
