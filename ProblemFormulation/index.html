Formal Problem Definition

Before an AI can search for a route, the problem must be formally defined.

1. States ($S$)

A representation of a physical configuration. Here, it is the specific waypoint the aircraft is currently located at.

$S = \{Start, A, B, C, Goal\}$

2. Actions ($A$)

The legal moves available from a given state. E.g., choosing which adjacent flight corridor to take next.

$A(s) = \{\text{Fly to } x, \text{Fly to } y\}$

3. Successor Function

The transition model. Given a state and an action, what is the resulting new state?

$T(s, a) = s'$

4. Goal Test

A function that evaluates the current state to determine if the mission objective is achieved.

Is $s == Goal$?
